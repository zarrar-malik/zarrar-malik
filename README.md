## How I work

| As an analyst | As a builder |
| --- | --- |
| Start from a real question, not a dataset, and work back to the data that answers it | Ship working apps and dashboards, not just notebooks |
| Clean and reshape messy, real-world data (CSV, Excel, PDFs, public APIs) | Build retrieval-augmented LLM tools with answers cited to the source |
